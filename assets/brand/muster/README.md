# Hintergrund-Muster

- `muster-smiley-zylinder-100.png` – Kachel 100×100 Pixel: Smiley mit Zylinder aus dem Favicon, in Graustufen, transparenter Hintergrund,
  nahtlos wiederholbar (ein Smiley in der Mitte, ein leicht schräger über die vier Ecken verteilt).
  Hochladen unter Funktionen → Bilder der Seite → Hintergrund-Muster.
- `muster-vorschau.png` – Vorschau: links gekachelt auf Grau, rechts wie auf der Seite (15 % auf dunklem Grund).
- `muster-erzeugen.py` – erzeugt die Kachel neu aus `assets/brand/favicon-master.png` (z. B. um Größe, Neigung oder Abstand zu ändern).
