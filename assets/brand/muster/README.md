# Hintergrund-Muster

- `muster-smiley-zylinder-100.png` – Kachel 100×100 Pixel, Smiley mit Zylinder in Graustufen, transparenter Hintergrund, nahtlos wiederholbar
  (ein Smiley in der Mitte, ein schräg gestellter über die vier Ecken verteilt). Hochladen unter Funktionen → Bilder der Seite → Hintergrund-Muster.
- `muster-smiley-zylinder.svg` – Vektor-Vorlage derselben Kachel (zum Ändern von Größe, Grautönen oder Abständen).
- `muster-vorschau.png` – Vorschau: links gekachelt auf Grau, rechts wie auf der Seite (15 % auf dunklem Grund).
